# Fantasy Premier League Data Pipeline

A data engineering project that ingests Fantasy Premier League API data into SQL Server, transforms it using dbt, ready for analytics.

## Features
- Python ingestion layer for multiple FPL API endpoints
- SQL Server raw data warehouse
- dbt transformations (raw → staging → analytics)
- Data quality testing with dbt tests
- Historical season support

## Tech Stack
- Python
- SQL Server
- dbt
- SQLAlchemy
- Git/GitHub
